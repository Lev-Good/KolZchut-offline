# שרשרת אופליין של אתר "כל זכות"

## מטרת הפרויקט

ארכיון אופליין מלא של אתר "כל זכות" (kolzchut.org.il) לשימוש אישי/קהילתי, עם אפשרות מאוחרת להסרת תכנים בעייתיים.
התוצר הסופי הוא **ZIP אחד** פתוח-לדפדפן, עם טקסט, קישורים בין דפים, אינדקס נושאים, חיפוש מקומי, ותיק עבודות.

## טכנולוגיות

- Python 3.14 + `requests`
- MediaWiki Action API: `https://www.kolzchut.org.il/w/he/api.php`
- ארכיטקטורה: Python שמייצר HTML סטטי + JavaScript מקומי לחיפוש (ללא שרת)

## מה כן ומה לא

| נכלל | לא נכלל |
|---|---|
| כל 7,371 דפי התוכן | תמונות (הוסר מההיקף לפי בקשת משתמש, 2026-10-11) |
| קישורים בין דפים | פאנל ניהול (יעשה דרך סקריפט נפרד בסיום) |
| אינדקס נושאים | דפי שיחה, היסטוריית גרסאות, דפי ויקי פנימיים מיוחדים |
| דף בית עם חיפוש מקומי | |
| ZIP סופי | |
