# החלטות ותיעוד החלטות

## 2026-10-11 — סנכרון דלתא מבוסס sitemap + אימות מחיקות בפועל

### החלטה
זיהוי שינויים/נוספו/נמחקו מתבצע החלטת מבדיקת ה-diff מסמסטמפ (NS0, מותר ב-robots.txt) בשילוב שני התפקידים:
1. **Backfill של `lastmod`** — אחרי הורדה מלאה מה-API בלי שמירת lastmod, האינדקס מקבל ערכים מה-sitemap פעם אחת, ואז ה-diff נקי.
2. **אימות מחיקות בפועל** לפני הסרה — HEAD לכל דף שה-sitemap השמיט. אם הדף קיים באתר (200) → נשאר בארכיון ומסומן false-positive. אם 404/410 או שגיאת רשת → גם לא מוסר לפני אימות.

### הסיבה
- ה-API מוגדר `Disallow` ב-robots.txt לכל בוט; sitemap ותיק-מקורות של עמודים מותר.
- בדיקה אמפירית גילתה שה-sitemap משמיט 10 דפים קיימים (לדוגמה: "פרישה לפנסיה" חוזר ה-200 באתר אך לא נמצא ב-sitemap). לכן עדכוני מחיקה בלבד-סמסטמפ אינם אמינים.

### השלכות
- הרצה יומית אמורה לרוץ ב-0 changed / 0 deleted בדרך כלל.
- `last_sync.txt` מתקדם רק כשהריצה שלמה; כשלים נשמרים ב-retry_queue.json.

## 2026-10-11 — ארכיטקטורה: HTML סטטי מה-API, ללא תמונות

### החלטה
הורדת תוכן באמצעות MediaWiki Action API והצורה בה נשמרים הדפים: HTML מעובד (action=parse) עם CSS משותף, אינדקס נושאים, חיפוש מקומי. ללא תמונות וללא פאנל ניהול.

### הסיבה
- ה-API ציבורי ופתוח (נבדק בפועל), התוכן מנוקה מהתחלתו.
- משתמש ביקש לוותר על תמונות ועל פאנל ניהול — ההסרה תיעשה בסקריפט נפרד בסיום.

### חלופות שנשקלו
- HTTrack/wget mirror — הרבה רעש, קשה לעבוד איתו, כולל דפי שיחה והיסטוריות.
- XOWA/Kiwix — מנוע כבד, יתירות, לא בהליך פשוט.

### השלכות
- ה-HTML יהיה נקי וקל, פורטל ראשי + חיפוש מקומי ב-JS מקומי.
- מהירות הורדה מוגבלת של בקשות בדקה, עם stop/resume.
